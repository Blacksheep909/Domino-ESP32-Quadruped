## HOTFIX: Domino Quadruped Studio 0.5.6 (firmware 0.8.29)

**Hotfix for 0.5.5, which could not start.** The installer left out a Policy Lab file, so Studio stopped at "Domino Quadruped Studio could not start its offline services". Install 0.5.6. Settings, calibration and gaits are kept. The firmware is unchanged at 0.8.29, so there is no need to reflash if you already did.

**Windows users on 0.5.5:** 0.5.5 can't open, so it can't update itself. Download the `.exe` below and run it.

- Studio now checks that every file it needs is in the installer before a release is built.

Everything new in 0.5.5 is included: the slate-blue theme, the Policy Lab, the Gaits preview fix, and Windows updates that report failures. See the [0.5.5 notes](https://github.com/Blacksheep909/Domino-ESP32-Quadruped/releases/tag/v0.5.5).

Windows and Apple-silicon Mac builds are attached.
